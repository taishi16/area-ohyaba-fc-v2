## D. V2推奨構成（Claude推奨・1案）

**静的HTML + CSS + Vanilla JavaScript**（フレームワーク・SSG・ビルド不要）

```
site/
  index.html          TOP
  club.html           クラブ（理念/歴史/エンブレム/地域）
  players.html        選手・スタッフ一覧（詳細はモーダル表示）
  matches.html        試合（NEXT / SCHEDULE / RESULTS / 年度切替）
  news.html           ニュース一覧
  news-detail.html    ニュース詳細（?id= で1ページ使い回し）
  assets/css/         CSS 1本
  assets/js/          データ取得＋描画 JS
  assets/img/         最適化済み画像（WebP + JPEGフォールバック）
  data/               スプレッドシートから生成したJSONのキャッシュ
```

- **年度が増えてもHTMLファイルは増えない**（データ側で完結）
- ページ数を11→6に集約。スマートフォンファーストで設計
- ビルド不要なので、将来ユーザーが別の人に引き継ぐときも読める

## E. 更新システムの推奨構成（コードを触らない運用）

**Googleスプレッドシート（5シート）＋ Google Apps Script（GAS）でJSON配信**

```
[Googleスプレッドシート]
  MATCHES / NEWS / PLAYERS / STAFF / SPONSORS の5シート
        ↓ （ユーザーは1行足すだけ）
[Google Apps Script Webアプリ]  ← 無料・認証不要・GASは個人Googleアカウントで動く
        ↓ JSON
[ホームページ] fetch でJSONを読み、その場で並べ替え・振り分けて描画
```

**なぜ「Publish to Web（CSV公開）」ではなくGASか**

| 方式 | 費用 | 問題点 |
|---|---|---|
| Publish to Web (CSV) | 0円 | シート全体が公開URLになる。列の追加・並べ替えで壊れやすい。CORSの挙動が不安定 |
| **GAS Webアプリ（推奨）** | **0円** | 公開する列をGAS側で明示的に選べる＝**非公開列を作れる**。JSON整形済みで壊れにくい |
| Google Sheets API | 0円 | APIキー管理が必要でユーザーの負担が大きい |

- GASは Google個人アカウントの無料枠で十分（1日あたりの実行時間上限90分に対し、想定使用量は数分）
- **公開対象の列を限定できる**ので、選手の生年月日・身長・体重などを「シートには持つが公開しない」運用も可能
- 表示が遅くならないよう、取得したJSONはブラウザ側で数分キャッシュする

**耐障害設計（重要）:** GASやスプレッドシートが一時的に落ちても、直前に取得したJSONをサイト側に静的ファイルとして持たせておき、そちらへフォールバックする。**「シートが見えない＝サイトが真っ白」にはしない。**

## G. Instagram連携の結論

### 調査結果

| 方式 | 費用 | 可否 | 判断 |
|---|---|---|---|
| Instagram Basic Display API | 無料 | **× 提供終了（2024年12月）** | 使えない |
| Instagram API with Instagram Login（Graph API） | 無料 | △ 技術的には可能 | **プロアカウント必須＋Metaアプリ作成＋アクセストークンを60日ごとに更新**。更新を忘れた瞬間に表示が止まる。→ 現行SnapWidgetが2年間壊れたまま気付かれなかった事実がリスクを裏付ける |
| SnapWidget（現行） | 無料枠 | **× 実質死亡** | 2年前のキャッシュを表示中。再接続しても同じ事が起きる |
| 非公式スクレイピング系 | 無料 | **× 禁止** | 要件により対象外 |
| **Instagram公式の投稿埋め込み（embed.js）** | **無料** | **○** | Metaアプリ・トークン**不要**。公開投稿のURLさえあれば公式に埋め込める |

### 推奨方式（半自動）

**「スプレッドシートの LATEST_ACTIVITY シートにInstagram投稿URLを3件貼るだけ」**

1. ユーザーはInstagramで投稿URLをコピー（アプリの共有→リンクをコピー）
2. スプレッドシートに貼る
3. TOPの LATEST ACTIVITY が公式埋め込みで切り替わる

- **費用0円 / トークン更新なし / Metaアプリ不要 / 数年放置しても壊れない**
- 加えて、Instagramプロフィールへの大きな導線ボタンを常設（貼り替えを忘れても「活動中」が伝わる導線を確保）

**将来:** どうしても完全自動が必要になった時点でGraph APIを追加できる設計にしておく（サイト構造は変えずに差し替え可能）。ただし要件34「高機能より無料・簡単・壊れにくい」に従い、初期リリースでは実装しない。
